# Aura Bottles – Interactive Showcase
This Figma project is a clean and interactive bottle advertisement design created to showcase four different bottles in a visually engaging way. The main screen presents four labeled frames, each representing a different bottle. When a user hovers over a frame, the corresponding bottle appears with its matching color theme, along with brief information displayed below it using smooth smart animations. Clicking on any frame opens a detailed page dedicated to that specific bottle, providing more in-depth information and a focused view. Users can easily navigate back by dragging, returning to the main screen. The design focuses on smooth transitions, clarity, and an intuitive browsing experience.
